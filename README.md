# User Management System – React.js & PHP

A simple and responsive **User Management System** built using React.js and PHP. This project demonstrates CRUD (Create, Read, Update, Delete) operations, allowing users to manage records through an interactive web interface.

## 🚀 Features

- **Create Users** – Add new user records.
- **View Users** – Display user information in a table.
- **Update Users** – Edit existing user details.
- **Delete Users** – Remove user records.
- **REST API Integration** – Connect the React frontend with the PHP backend.
- **Responsive Interface** – User-friendly interface for managing records.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/jacapistrano/user-management-react-php.git
```

### 2. Navigate to the Project

```bash
cd user-management-react-php
```

### 3. Set Up the Backend

Navigate to the backend folder:

```bash
cd backend
```

Make sure PHP is installed and configure your database connection if required.

Start the PHP development server:

```bash
php -S localhost:8000
```

### 4. Set Up the Frontend

Open another terminal and navigate to the frontend folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the React development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
